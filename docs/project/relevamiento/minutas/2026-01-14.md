2.1. Venta de Normas

Se solicitó que el cliente pueda realizar el pago directamente desde el portal web mediante la implementación de una pasarela de pagos, ya que actualmente el proceso se realiza por transferencia bancaria manual.

Se solicitó incluir los datos institucionales del INTN en el apartado de tienda del portal web para consultas de los clientes.

Se solicitó que el archivo PDF generado para el cliente cuente con una restricción de impresión.

2.2. Básculas

Se indicó la necesidad de realizar una limpieza de datos debido a la existencia de información innecesaria en el sistema.

Se solicitaron mejoras generales para optimizar el funcionamiento del sistema actual, incorporando la automatización de procesos que actualmente se realizan de forma manual.
