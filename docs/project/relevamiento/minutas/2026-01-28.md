2. Observaciones y problemáticas identificadas por área

A continuación, se detallan las principales observaciones identificadas durante el relevamiento, destacándose los puntos más relevantes de la reunión.

2.1. DSE

Durante el relevamiento con el área de DSE se identificó que actualmente utilizan un sistema independiente a ODOO para la gestión de sus procesos.

En esta instancia se relevó el funcionamiento actual y, en conjunto con el área, se trabajó en la definición del flujo de proceso esperado dentro de ODOO, contemplando la habilitación de Organismos de Inspección, la autogestión del cliente desde el portal web y la posterior operación dentro del módulo correspondiente.

El flujo definido establece las etapas desde la solicitud inicial del cliente, la validación por parte del DSE, la generación del expediente y el acceso al portal, hasta la gestión de informes y el control de cumplimiento.

Este esquema servirá como referencia funcional para el diseño y desarrollo de la solución.

2.2. Precintados

En el área de Precintado se identificó que actualmente operan con un sistema propio. Durante el relevamiento se analizó dicho funcionamiento y se trabajó en el flujo esperado dentro de ODOO, evaluando tanto la posibilidad de su implementación directa como su integración con el sistema ya existente.

Asimismo, se relevó la necesidad de integrar el sistema TRA, que gestiona el stock de cajas de precintos, a fin de permitir el control de inventario (disponibles, utilizados y descartados).

En base a lo conversado, se definió un flujo de proceso esperado que servirá como referencia para la automatización e integración de estos componentes en el sistema.
