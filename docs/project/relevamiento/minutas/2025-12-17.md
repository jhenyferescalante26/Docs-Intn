Resumen

Cierre del Relevamiento Previo

José informó al equipo que querían cerrar el relevamiento previo que habían estado realizando con el equipo de Diego. Mencionó que después de algunas consultas, aparecieron pendientes con los documentos que Teresa había compartido. Leonardo pidió que le reenviaran los correos.

Problemas Técnicos Envío Documentos

El equipo discutió problemas técnicos con el envío de documentos por correo electrónico, donde los correos llegaron al spam y algunos documentos no se adjuntaron correctamente. José acordó presentar un calendario propuesto para la entrega del proyecto y obtener aprobación del equipo. Leonardo solicitó que se proyectara la información del correo para revisarla y que Teresa compartiera el organigrama para identificar las áreas y servicios involucrados.

Organización de Servicios en Sistema

Teresa informó que hay 5 000 servicios vigentes clasificados por laboratorio, departamento y organismo en el sistema de productos. Los participantes discutieron cómo estos servicios se organizan y cómo algunos están compartidos entre diferentes organismos como Onece y OYET. Leonardo sugirió actualizar los servicios existentes en lugar de añadir nuevos para agilizar el trabajo, y Teresa acordó que es necesario mejorar los flujos actuales para reflejar las particularidades de cada servicio.

Revisión Categorías Sistema

Leonardo, Teresa y José discutieron sobre las categorías en el sistema, buscando confirmar el alcance y si se mencionaban todas las áreas requeridas. Teresa mostró en pantalla la estructura actual, pero confirmó que la categoría no se utiliza en el sistema como se esperaba. Leonardo solicitó a Teresa que proporcionara las categorías correctas para la nueva implementación.

Organización de Productos y Determinaciones

Teresa y Leonardo discutieron la organización de productos y determinaciones en un sistema. Teresa explicó cómo los productos se agrupan por determinación y demostró la estructura del sistema donde los productos se categorizan bajo determinaciones como "alimentos y aceite" con subcategorías como "sabor". Leonardo y Teresa identificaron que algunos datos de determinación necesitan actualización ya que fueron ingresados incorrectamente durante el relevamiento inicial.

Implementación de Sistemas INTN

Leonardo, Teresa y José discutieron los requisitos y procesos del proyecto de implementación de sistemas para INTN. Leonardo identificó la información necesaria para el relevamiento físico, incluyendo formatos de facturas, notas de crédito, libro de ventas y categorías de servicios. El equipo acordó un cronograma tentativo de seis meses que incluye validación de flujos, desarrollo, pruebas funcionales y capacitación. Se programó el inicio del proyecto para el 8 de enero, dependiendo del regreso de vacaciones de Teresa el 5 de enero. Andrea, la directora, enfatizó la importancia de abordar tanto el sistema actual como el sistema alternativo en paralelo durante el relevamiento.
