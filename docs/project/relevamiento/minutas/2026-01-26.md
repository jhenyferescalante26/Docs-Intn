2. Observaciones y problemáticas identificadas por área

A continuación, se detallan las principales observaciones identificadas durante el relevamiento, destacándose los puntos más relevantes de la reunión.

2.1. ONI

Se informó que actualmente el proceso de generación de órdenes de trabajo en el área de Metalurgia contempla cinco pasos, solicitando su simplificación y optimización dentro del sistema.

Desde el portal web, se solicitó que el cliente pueda visualizar el estado de su servicio, contemplando los siguientes estados:

Recepcionado

En proceso

Informe disponible

Se indicó que actualmente el sistema no se utiliza para la generación de informes, debido a que el formato disponible no es el adecuado, por lo que se requiere su automatización.

Se solicitó que el sistema permita gestionar y visualizar los siguientes datos del expediente:

Fecha de recepción (fecha de ingreso al departamento)

Fecha de creación del expediente

Datos del cliente

Número de expediente

Datos de la muestra (cantidad y descripción)

Se solicitó incorporar un campo de estado del expediente, con las siguientes opciones:

Confirmado

Contado

Crédito

Se planteó la necesidad de que cada informe cuente con un código único o código QR, para facilitar su validación.

2.2. ONC

Se realizó el relevamiento correspondiente al Departamento de Personas, con el objetivo de completar el análisis de los procesos del ONC. Durante la reunión se validó que este departamento sigue una lógica de trabajo alineada a los flujos ya relevados en los Departamentos de Sistemas y Productos.

En la sesión se esquematizó el flujo de trabajo del Departamento de Personas dentro del sistema, definiendo cómo se integran sus actividades al proceso general de certificación, desde la gestión de las solicitudes hasta su vinculación con los expedientes, y documentación asociada.

Este relevamiento permitió cerrar el esquema funcional del ONC, contando ya con los flujos de los tres departamentos que lo componen, como base para el diseño e implementación del sistema.

2.3. ONM - UMCI

La reunión dio continuidad al relevamiento realizado previamente con el área, en el cual ya se habían identificado algunos requerimientos.

En esta instancia se incorporaron nuevos puntos y, además se trabajó en la definición del flujo de proceso esperado dentro del sistema.

Se indicó que, en la mayoría de los casos, el servicio sólo puede ejecutarse una vez que el mismo se encuentre pagado.

Se mencionó la necesidad de integrar el sistema ODOO con el sistema TRA.

Se informó que existen laboratorios que trabajan con y sin agendamiento, lo cual debe ser considerado en la implementación.

Actualmente se genera de forma manual un documento que certifica la devolución del instrumento por parte del cliente; se solicitó que este documento sea gestionado desde el sistema.

Para los casos de trabajo no realizado, también se emite un informe en formato manual, el cual deberá incorporarse al sistema.

Desde el portal de autogestión, el cliente deberá poder indicar el tipo de instrumento, para que el INTN pueda validar y asignar correctamente el servicio.

El área sugirió la integración del sistema METRA. con el ODOO.
