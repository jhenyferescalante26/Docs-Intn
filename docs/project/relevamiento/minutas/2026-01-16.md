1. Relevamiento de áreas:

Tesorería - AquíPago

METCI

Durante la reunión, los referentes de cada área explicaron el uso actual del sistema, los procesos que realizan y las dificultades que enfrentan en la operativa diaria.

2. Observaciones y problemáticas identificadas por área

A continuación, se detallan las principales observaciones identificadas durante el relevamiento por área, destacándose los puntos más relevantes de la reunión.

2.1. Tesorería - Aquí Pago

Se abordó la implementación del pago a través de AquíPago de manera en línea, integrado al sistema

Se planteó la posibilidad de incorporar búsquedas por RUC, número de factura o cédula para facilitar la búsqueda (ya que un solo RUC puede tener muchas sucursales y por ende muchas facturas)

Se mencionó la necesidad de definir el canal de comunicación para la integración (VPN o IP pública).

Se solicitó que las cajas puedan operar de forma independiente.

2.2. METCI

Gestión de solicitudes de calibración directamente desde el portal web del cliente, incluyendo la visualización del presupuesto.

Visualización y aprobación de presupuestos en línea, considerando que actualmente el presupuesto se prepara de forma manual y tiene un plazo de vigencia.

Se solicitó que el cliente pueda registrar datos de personal tercerizado, en caso de que la persona originalmente asignada no pueda presentarse.

Se solicitó que, desde el portal, se pueda registrar el tipo de servicio, in situ o en laboratorio, con cálculo automático de costos adicionales.

Necesidad de contar con un calendario de servicios, que permita bloquear fechas o períodos en los que no se puedan realizar calibraciones.

Se solicitó la incorporación de un código QR para la validación de certificados.

Se mencionó la existencia de un sistema independiente, el cual deberá ser integrado al sistema actual ODOO.

2. Puntos Acordados

AquíPago se comprometió a proporcionar la documentación del webservice

La Sra. Sonia Chang se comprometió a remitir las documentaciones referente al área METCI.
