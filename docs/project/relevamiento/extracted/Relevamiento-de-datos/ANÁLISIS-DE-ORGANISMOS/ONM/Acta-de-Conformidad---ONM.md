Presente:

En el marco del relevamiento realizado con los distintos departamentos del Organismo Nacional de Metrología “ONM”, se elaboró esquemas de flujos de procesos con actores que describen el funcionamiento propuesto del sistema Odoo.

Dichos esquemas servirán como referencia para definir los lineamientos base y el alcance funcional que dará inicio a la etapa de desarrollo de la nueva versión de Odoo y migración de datos.

En ese sentido, se solicita la Conformidad de los esquemas adjuntos realizados con los Departamentos correspondientes de “ONM”, el cual No implica el sistema definitivo, sino la aceptación de los flujos como marco base de referencia para el inicio de implementación.
