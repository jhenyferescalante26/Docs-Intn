Sres. Instituto Nacional de Tecnología, Normalización y Metrología (INTN)

Presente:

En el marco del relevamiento realizado con los distintos departamentos del Organismo Nacional de Normalización “ONN”, se elaboró un esquema de flujos de procesos con actores que describe el funcionamiento propuesto del sistema Odoo.

Dicho esquema servirá como referencia para definir los lineamientos base y el alcance funcional que dará inicio a la etapa de desarrollo de la nueva versión de Odoo y migración de datos.

En ese sentido, se solicita la Conformidad del esquema adjunto realizado el 27 de enero con los Departamentos correspondientes de “ONN”, el cual No implica el sistema definitivo, sino la aceptación de los flujos como marco base de referencia para el inicio de implementación.
