Dicho esquema servirá como referencia para definir los lineamientos base y el alcance funcional que dará inicio a la etapa de desarrollo de la nueva versión de Odoo y migración de datos.

En ese sentido, se solicita la Conformidad del esquema adjunto realizado el 26 de enero con los Departamentos correspondientes de “ONI”, el cual No implica el sistema definitivo, sino la aceptación de los flujos como marco base de referencia para el inicio de implementación.
