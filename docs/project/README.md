# Registros de proyecto

Material contractual e histórico del proyecto INTN. **No es documentación de usuario ni técnica** — para eso ver [`docs/admin/`](../admin/README.md), [`docs/portal/`](../portal/README.md) y [`docs/technical/`](../technical/README.md).

| Carpeta / archivo | Contenido |
|-------------------|-----------|
| `relevamiento/` | Relevamiento original, minutas, pliego, matriz contractual y texto extraído |
| `user-stories/` | User stories por sprint y criterios de aceptación |
| `migration-data/` | Plan de migración de datos v12 → v18 |
| `demo-data/` | Matrices de cobertura de datos demo |
| `test-specs/` | Notas de especificación de pruebas |
| `i18n/` | Artefactos de traducción es_PY |
| `tasks.csv` | Export histórico de tareas |
